# Portfolio — Ibrahim Belayachi

Portfolio personnel en HTML, CSS et JavaScript, avec recherche interactive, thème clair/sombre et documents intégrés.

## Lancer le site

Téléchargez le dépôt (Code → Download ZIP), décompressez-le et ouvrez `index.html` dans votre navigateur. Aucune installation ni clé API n’est nécessaire. Les polices Google nécessitent Internet ; les polices système prennent le relais hors ligne.

Vous pouvez aussi utiliser un serveur local avec Python 3 :

```bash
python3 -m http.server 8000
```

Ouvrez ensuite http://localhost:8000.

## Publier avec GitHub Pages

Dans les paramètres du dépôt : **Settings → Pages → Build and deployment → Deploy from a branch**, sélectionnez **main**, dossier **/ (root)**, puis **Save**.

Le site sera disponible à l’adresse https://Ibrahim-bel.github.io/portfolio/ après le déploiement.
